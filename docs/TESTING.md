# 验证范围

## v1.2.0

74 项逻辑测试通过。测试使用假硬件、假监护进程及可控时钟，不调用实际驱动，可直接运行：

```powershell
dotnet run --project ./tests/FanControl.Tests --configuration Release
```

覆盖内容：

- 全部 101 个百分比的 PWM 转换、遥测解析和转速换算。
- CPU/GPU 独立控制、不同目标同时应用、第三路保持自动。
- 单路及全部恢复自动，监护进程在硬件写入前就绪。
- 驱动读写失败、传感器失效、监护进程退出后的自动重连。
- 1、2、4、8、10 秒退避重试、恢复已应用目标及取消待恢复目标。
- 85°C 保护、75°C 释放门限、重连时温度检查及保护锁定保留。
- 固件覆盖手动值后的读回冲突处理。

Release 构建通过，0 警告、0 错误。HASEE CNP6S 上已进行界面与基础调速验证，使用者反馈正常。

实机故障注入、休眠/注销及高温压力测试不属于本次自动化验证；逻辑测试不能代替这些硬件场景。

## 初版实机观测

在适配机型上曾观测到 CPU 0% 对应 0 RPM、100% 对应约 6,361 RPM，正常关闭及主进程异常退出可恢复自动。

RPM 是观测值，不是固定规格。PWM 占空比与实际 RPM 不呈线性关系。

本机诊断输出、程序日志及厂商反编译研究文件不随开源仓库分发。
